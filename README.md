## 📖 Deep-Dive Technical Documentation

# Domain Infrastructure Checker

A sleek, powerful, and single-file web application to instantly analyze core DNS records (A, CNAME, MX) for any domain. Built with a dark, immersive "nebula" theme for a great user experience.

## Features

- **Instant DNS Lookups:** Quickly query A, CNAME, and MX records.
- **Sleek Dark UI:** A modern, visually appealing dark theme with an animated cosmic background.
- **Fully Responsive:** Works beautifully on desktop, tablet, and mobile devices.
- **Zero Dependencies:** A single `index.html` file that runs in any modern browser. No installation needed.
- **User-Friendly:** Clear status indicators and well-structured results.
- **SEO Optimized:** Semantic HTML and relevant metadata for better discoverability.

## How to Use

Simply download the `index.html` file and open it in your web browser.

1.  Enter a domain name (e.g., `google.com`) in the input field.
2.  Click the **"Analyze DNS"** button.
3.  View the results displayed in categorized cards.

## Technologies Used

- **HTML5:** For the core structure and content.
- **Tailwind CSS (via CDN):** For modern, utility-first styling and responsiveness.
- **Vanilla JavaScript:** For all client-side logic, including API calls and DOM manipulation.
- **Google Public DNS API:** The public, CORS-enabled API used to fetch DNS records.
